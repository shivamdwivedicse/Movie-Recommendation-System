# 🎬 Movie Recommendation System

A Machine Learning based Movie Recommendation System that suggests similar movies based on the movie selected by the user.

This project demonstrates how recommendation engines used by platforms like Netflix and Amazon work at a basic level.

Try it live :- https://movie-recommendation-system-wsddchynctlc6vl6jvxf2h.streamlit.app/

---

## 🚀 Features

- Select any movie from the dropdown
- Get 5 similar movie recommendations instantly
- Simple and interactive web interface
- Built using Streamlit

---

## 🧠 How It Works

The system recommends movies using **content-based filtering**.

1. Movie metadata is processed using **NLP techniques**
2. Text data is converted into numerical vectors
3. **Cosine Similarity** is used to calculate similarity between movies
4. The most similar movies are recommended to the user
